# Architectural Decisions

This directory contains Architectural Decision Records (ADRs) for the Pune Water Network AI project.

## Format

Each decision is recorded in a separate file named `NNN-short-title.md` where `NNN` is a zero-padded sequence number.

## Template

```markdown
# ADR-NNN: Title

**Date:** YYYY-MM-DD  
**Status:** Proposed | Accepted | Deprecated | Superseded  
**Deciders:** Team member names

## Context

What is the issue that motivates this decision?

## Decision

What is the change that we're making?

## Rationale

Why is this the right choice?

## Consequences

What becomes easier or more difficult because of this decision?
```
