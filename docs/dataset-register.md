# Dataset Register — Pune Water Network AI

> **Status:** Under Investigation. No dataset has been confirmed available, licensed, or downloaded. This register records sources examined and their suitability.

**Owner:** All team members (update when evaluating any dataset)

---

## Purpose

This register records every dataset examined or used in the project, including:
- Dataset name and source
- Data type and format
- Geographic coverage
- Licence and usage restrictions
- Availability status
- Suitability assessment
- How to cite if used

**Important:** Do not invent or fabricate real pipeline data. Clearly label all synthetic data as synthetic.

---

## Format

Each entry should follow this template:

```
### Dataset Name

| Field | Value |
|-------|-------|
| Source | URL or organisation |
| Type | (e.g., pipeline GIS, sensor telemetry, administrative boundary) |
| Format | (GeoJSON, CSV, Shapefile, API, etc.) |

| Status | Under investigation / Available / Not available / Not suitable |
| Evaluated by | Team member name |
| Evaluation date | YYYY-MM-DD |

Notes: ...
```

## Provenance Requirements

All data files used in the project must have:
1. Source URL or citation recorded in this register
2. Copy of the licence or usage terms in `data/raw/<dataset-name>/LICENSE.txt`
3. A README in `data/raw/<dataset-name>/README.md` explaining what the data is
4. Clearly marked as REAL or SYNTHETIC in metadata

Do not commit actual data files to Git (they are excluded by `.gitignore`).
