# API Contract Examples

This directory contains example request and response JSON files for the API endpoints defined in `../openapi.yaml`.

These examples serve as:
- Documentation and communication aids for the team
- Test fixtures for frontend mocking
- Reference for backend response validation

## Structure

Files are named after the endpoint they document:

```
examples/
├── health-response.json
└── (more examples to be added as endpoints are implemented)
```
